## Your first conversation

<Steps>
  <Step title="Open Chat">
    [Go to Chat](https://anistratenco.com/chat) and sign in. Choose New chat. If the sidebar is hidden, use Expand sidebar.
  </Step>
  <Step title="Say what you want to understand">
    Write in Chat message. Say what you want explained and include any context you already know.
  </Step>
  <Step title="Bring in the context">
    Use Add attachment for a relevant file or Record voice to speak. Check the message or transcript, then choose Send message. You can add more in a follow-up.
  </Step>
  <Step title="Work with the answer">
    Ask a follow-up, open the cited sources, and correct anything that is wrong. Ask for more detail where it matters or a shorter explanation where it does not.
  </Step>
</Steps>

<div className="help-panel">
  <h3>For example</h3>
  <p>“Help me understand this result. Explain what was measured, what context is missing, and which questions would be useful to ask next.”</p>
</div>

## Give the conversation continuity

Return to an earlier chat when you have an update. Use a project for related conversations and files, and review saved context in Memory history.

<CardGroup cols={2}>
  <Card title="Return to a conversation" icon="clock-rotate-left" href="/archived-chats">
    Use history to pick up earlier work. Archiving puts a chat away without deleting it.
  </Card>

  <Card title="Review saved context" icon="brain" href="/memory">
    See what the Assistant remembers. Correct it or remove what no longer belongs.
  </Card>
</CardGroup>

Create project starts a space for related work. When you need a different direction from one answer, Continue in new chat creates a separate conversation. Copy and Read aloud help you use an answer in the form that suits you.

## When you need a hand

[Contact us](/contact) for a product problem, or [check service status](https://status.anistratenco.com) when something is unavailable. If a response shows an error reference, keep it with your report. Before repeating an action that sends, books, buys, or changes something elsewhere, check whether it completed.

<section className="help-faq" aria-labelledby="getting-started-questions">
  <h2 id="getting-started-questions">Questions and Answers</h2>
  <Accordion title="What should I ask first?">Start with something you want to understand now. A question, a result, or a goal is enough. You can make it more specific as you go.</Accordion>
  <Accordion title="Do I need to upload my health history?">No. Begin with the context relevant to your question. You decide what to share and can add more when it helps.</Accordion>
  <Accordion title="Can I correct something after sending?">Your messages can offer Edit and Delete. You can also explain the correction in a follow-up. Review saved information separately in Memory history.</Accordion>
  <Accordion title="Where do I change voice or text size?">Open Settings from your profile menu. Choose Voice for audio controls and Appearance for text size and display options.</Accordion>
  <Accordion title="Does opening an app connect it?">Opening an app starts its own connection flow. Check that the flow reports success before treating the app as connected.</Accordion>
</section>
