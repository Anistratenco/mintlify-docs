## Files in your account

The **Files in your account** card shows storage used by uploaded files, which are available across your signed-in devices. Select the card to open Files. This storage is separate from the browser cache below.

## Browser settings cache

The meter covers settings and temporary workspace data in this browser. Its used and total values describe this browser-local cache, not account file storage or all storage on your device.

## Download account data

Choose **Download account data** in **Settings → Data**. The export contains three parts:

- `anistratenco-account-data.json` lists account data inventory metadata. It does not contain the underlying record contents.
- `anistratenco-personal-records.ndjson` contains server-stored conversations and messages, projects, personal health records, notes, uploaded-file metadata, and Voice state.
- Uploaded file contents are downloaded as individual files.

This export does not include browser-local data or payment-provider data. It is a portable account copy, not a backup or restore file for this browser. Keep downloaded copies private.

Some exports require recent identity verification. If **Open Security settings** appears, finish verification in Security, return to Data, and try again.

If an export fails partway through, read the message to see which step failed. Check your download location for files already saved; a retry does not remove them. Choose **Download account data** again to retry.

For a data-access, deletion, correction, export, restriction, or privacy request, open [Contact us](/contact) and select **Privacy request**. Then choose **Access my data**, **Delete my data**, **Correct my data**, **Export my data**, **Restrict or object**, or **Privacy question**.

## Clear cache

If **Clear cache** appears, it is because this browser has locally persisted chat state. Choose it only when you are ready to clear that local state, then confirm with **Clear**. The action reloads the page and does not delete server-held account data. The account export does not include this browser-local cache, so it is not a backup for it.

If the app says the browser cache could not be completely cleared, treat the result as incomplete and follow the message shown in the app.

## Delete all chats and Delete all projects

These actions appear when there is content to remove. Read the confirmation and check whether you are deleting chats or projects.

A brief **Undo** action is offered in the app notification for these bulk chat and project actions. Use it immediately if you made a mistake; do not treat it as a permanent recovery option. Archiving a chat is different from deleting it.

## Reset everything

Reset locally stored app data and reload. In the current app, this uses the same broad local clearing operation as Clear cache. It does not mean that all information held by every service has been erased.

## Delete account

Account deletion is a separate, permanent action. Open its confirmation and read the scope before continuing. It is not a troubleshooting step for a display or connection problem.

If deletion or cleanup reports a failure, follow the displayed recovery instructions rather than assuming every step finished. Use the privacy request route above for data rights questions.
