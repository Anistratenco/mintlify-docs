Choose how you write messages and follow replies. Open your profile menu in the sidebar, then **Settings → Preferences**.

## Submit messages with

Choose the keyboard shortcut that feels natural when you write.

| Setting | Send your message | Start a new line |
| --- | --- | --- |
| Enter | Enter | Shift + Enter |
| Shift + Enter | Shift + Enter | Enter |

Choose **Shift + Enter** if you often write several paragraphs and want Enter to add a line rather than send. You can still use the **Send message** button. This setting does not send an empty message or interrupt text composition in an input method.

## Auto-scroll

Keep the latest reply in view while it arrives. If you scroll upward to read something earlier, the app stops following the live reply so you can keep reading. Return to the bottom to follow it again.

Turn Auto-scroll off if you prefer to control your position yourself. It changes scrolling, not whether the assistant continues working.

## Context window meter

Show a small context-usage indicator near the message box when measured usage is available. It represents how much of the model's available input context was used for the latest completed turn.

Context includes more than your visible messages: instructions and tool information can use space too. This is not a count of saved conversations, a storage meter, or your remaining subscription allowance. Turning the meter off only hides the indicator; it does not give the model more memory.

## Add Files to sidebar

Show a **Files** entry in the sidebar for quicker access. Turning this off hides the shortcut; it does not delete your files.

## Read responses aloud

Listen to new assistant answers when they finish. This is the same response-audio preference available under Voice, not a second independent setting.

For playback speed, speech engine, language, and voice choices, see [Voice and transcription](/voice#read-responses-aloud).

## Workspace shortcuts

**Open Apps workspace**, **Open Skills workspace**, and **Open Automations workspace** take you to those management areas. Opening an area does not connect an account, install a skill, or schedule anything by itself.

## Need help?

For a setting that does not behave as expected, [contact us](https://anistratenco.com/contact) and choose **Report a bug**. Describe the setting, the action you took, and what happened. For a new capability, use the [feature roadmap](https://anistratenco.userjot.com).
