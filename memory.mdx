The earlier Memory history guide described cross-conversation consent, memory search, review, correction, import, suppression, and deletion controls. These features are no longer available in the current Health Assistant. You will not find **Settings → Avatar → Memory history**, **What Chat remembers**, or the old import and memory review flows.

The retirement of these controls does not confirm that information saved by earlier versions has been erased. Do not assume that older data has been removed just because the controls are unavailable.

## What you can do now

- Continue in the same conversation when you need its history. Use a project to organize related conversations and files.
- For the current account export, browser cache, and deletion controls, see [Data export and deletion](/data).
- To ask about access, correction, or deletion of account data, open [Contact us](/contact) and choose **Privacy request**. The Data guide lists the available request types.
