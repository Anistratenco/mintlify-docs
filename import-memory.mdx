<Visibility for="agents">
Import is a user-driven structured-memory transfer, not provider authentication or automatic history synchronization. Named providers supply a prompt; JSON also supports file selection. The preview shows five entries and processes at most 128 records per batch. Duplicate records are skipped; conflicts are retained for review. The current provider prompt omits the required owner-versus-family-history classification. Do not claim that its output always imports successfully. Only a completed import saves records; do not infer cross-device synchronization from local success.
</Visibility>

Bring selected memories from another assistant or an Anistratenco JSON export. Review the information first, then choose what to keep in your account.

<div className="help-panel">
<Steps>
<Step title="Open Import" icon="file-import">Open **Settings → Avatar → Memory history**, then choose **Import**.</Step>
<Step title="Prepare your memories" icon="file-code">Choose a source and prepare a supported JSON export. Review the complete export before you paste it.</Step>
<Step title="Check, then save" icon="check">Read the preview and its counts. Choose **Import memories** only when you are ready to keep the records.</Step>
</Steps>
</div>

Import adds supported records to your account's local memory. It does not transfer an entire account or every conversation.

## Prepare the export

For a named source, open **Preview prompt** to inspect the request. Choose **Copy**, paste the prompt into the service where your information already exists, and review its reply. Another assistant may leave things out or summarize them incorrectly.

<Warning>
The current built-in provider prompt is incomplete: the importer also needs records to identify whether information is about you or family history. A reply that follows the prompt can still be rejected. If that happens, use a compatible Anistratenco JSON export, add a few memories manually, or contact support. Repeatedly submitting the same reply will not correct it.
</Warning>

Do not include passwords, recovery keys, unrelated third-party details, or information you do not want retained.

## Read the preview

Paste the JSON reply into the import field, or choose a file in the **JSON** source screen. The app shows a preview or an error. **A preview is not a completed import.**

<div className="help-panel">
### What each state means

<Tabs>
<Tab title="New" icon="plus">
The record is ready to add. Check that it describes something you want the assistant to remember—not a guess you want treated as a fact.
</Tab>
<Tab title="Duplicate" icon="copy">
The record is already represented in your memory and will be skipped. You do not need to add it again.
</Tab>
<Tab title="Needs review" icon="triangle-exclamation">
The record conflicts with existing memory. It will be imported with the conflict preserved, not silently corrected. Review it afterward using the **Conflicts** filter.
</Tab>
</Tabs>
</div>

| Check | What to look for |
| --- | --- |
| Preview | Only the first **five entries** are shown. Review the full source export too. |
| Batch size | At most **128 memories** are processed per batch. Use smaller reviewed batches when needed. |
| Import count | The button shows how many records will be added after duplicate handling. |
| Unwanted information | There is no per-entry selection in this preview. Edit the source export before importing. |

## Save and review

<div className="help-panel">
<Steps>
<Step title="Import" icon="download">Choose **Import memories**, or the button showing the number ready to import. It is unavailable if the preview is invalid or nothing new can be added.</Step>
<Step title="Wait for the result" icon="clock">An **Importing…** state means the save is still in progress. Keep your original export if the operation fails.</Step>
<Step title="Review what you kept" icon="brain">After success, return to **What Chat remembers**. Inspect the new information and use **Conflicts** for anything needing attention.</Step>
</Steps>
</div>

Use the [memory review controls](/memory#review-memories-together) to manage what was added. Import does not certify that a record is accurate. Local success also does not guarantee that all devices have synchronized; check [Devices & sync](/devices).

[Contact us](https://anistratenco.com/contact) if you cannot complete the import.

<section className="help-faq" aria-labelledby="page-questions">
<h2 id="page-questions">Questions and Answers</h2>
<Accordion title="Why can't the JSON be read?">
Use raw structured JSON without surrounding prose or a Markdown code fence. A valid JSON file can still contain no supported memory records; it needs to be a compatible memory export.
</Accordion>
<Accordion title="Why does the app ask whose information this is?">
The records need to distinguish your information from family history. The built-in prompt currently omits this requirement. Use a compatible Anistratenco export, add the memories manually, or ask support for help.
</Accordion>
<Accordion title="What does Already imported mean?">
There are no new records to add. Check your existing memory rather than submitting the same export repeatedly.
</Accordion>
<Accordion title="What if the memories could not be saved?">
Keep your original export. Use the displayed error or support reference when contacting us. Do not send the full export by default—it may contain sensitive health and personal information.
</Accordion>
<Accordion title="Does choosing a provider connect my account?">
<div>No. You copy a prompt and bring back a supported structured export. The picker does not sign in to the provider or automatically fetch your history.</div>
</Accordion>
<Accordion title="Is everything saved as soon as I upload?">
<div>No. Review the preview first, then choose Import memories. An upload or preview alone does not save the records.</div>
</Accordion>
<Accordion title="Can I choose individual records in the preview?">
<div>No. Edit the source export or prepare a smaller batch if you do not want to import every eligible record. The preview shows only the first five entries, so review the complete source before saving.</div>
</Accordion>
<Accordion title="What happens to a conflicting memory?">
<div>It is imported with the conflict preserved. Review it afterward with the <strong>Conflicts</strong> filter instead of assuming the newer statement replaced the older one.</div>
</Accordion>
<Accordion title="Should I delete the original export after importing?">
<div>Keep it until you have reviewed the imported records and confirmed the result. Store it somewhere private because it may contain sensitive health and personal information.</div>
</Accordion>
