The memory import flow described in older help is no longer available in the current Health Assistant. There is no provider picker, JSON memory import, or **Import memories** control to use. Do not upload an old export expecting it to be added as saved context.

Downloaded files remain separate copies. For the current account export, browser cache, and deletion controls, see [Data export and deletion](/data). For a privacy request about information held in your account, open [Contact us](/contact) and choose **Privacy request**.

If you would like to suggest a new import feature, use the public [Feedback board](/feedback). Do not post health records, private conversation details, or account credentials there.

<h2 id="page-questions">Questions and answers</h2>
<Accordion title="Can I import a memory file into the Health Assistant?">
<div>No. The earlier memory import flow is not available in the current product.</div>
</Accordion>
<Accordion title="Does a downloaded export get deleted when import is unavailable?">
<div>No. A downloaded file remains a copy on your device. Keep it private and do not assume the current app can restore it.</div>
</Accordion>
<Accordion title="Does the old provider picker connect another account?">
<div>No. The provider picker described in older help is no longer available, and this page does not start an account connection.</div>
</Accordion>
<Accordion title="Where can I review current account exports and deletion?">
<div>Open <a className="link" href="/data">Data export and deletion</a> for the current account export, browser cache, and deletion controls.</div>
</Accordion>
<Accordion title="How do I suggest an import feature?">
<div>Use the public <a className="link" href="/feedback">Feedback board</a> and describe the goal without health records or credentials.</div>
