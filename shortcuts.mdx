Open your profile menu, then **Settings → Shortcuts**. Use a desktop-sized window to change a shortcut, confirm it, or switch it off.

## The available shortcuts

Use **Command** on Mac or **Ctrl** on Windows and Linux where the table says Command/Ctrl. Your settings show the keys for your device.

| Setting | Default keys | What it does |
| --- | --- | --- |
| Toggle search | Command/Ctrl + K | Opens or closes chat search. |
| Focus composer | / | Moves your cursor to the message box when you are not already typing in a field. |
| Select transcript | Command/Ctrl + A | Selects the visible chat text when you are in Chat, outside an editable field, with search closed. |
| Open settings | Command/Ctrl + , | Opens Settings and closes chat search. |
| Open files | Command/Ctrl + Alt + F | Opens Files and closes chat search. |

**Select transcript** does not copy text to the clipboard by itself. Copy the selection afterward. It is not a full conversation export: messages that are not currently rendered may not be included. Inside a text field, the usual select-all behavior still applies to that field.

## Change a shortcut

1. Select the current key combination beside the action. If no combination is shown, choose **Configure**.
2. Press the combination you want to use.
3. Choose **Confirm** to save it, or **Cancel** to keep the previous setting.

The app checks for combinations reserved by the browser or system and for conflicts with another command. If a warning appears, choose a different combination. Saving a new combination also enables that shortcut.

For **Focus composer**, keep the default **/** for now. Modified combinations using Command, Ctrl, or Alt are not handled by this action in the current app.

## Switch a shortcut off

Use the switch beside an action to disable its keyboard shortcut. This does not remove the feature: you can still open it with the app controls. Switch it back on to use the shortcut again.

## Restore the defaults

Use the reset icon beside a changed or disabled shortcut to restore its default keys and enable it.

**Reset shortcuts** resets all custom combinations and re-enables disabled shortcuts. It does not delete chats, files, or other settings.

## If a shortcut does not respond

Check that it is enabled and that you are using the combination displayed in Settings. Your browser or operating system may also use that combination. For **/**, click outside a text field first; for **Select transcript**, close search and return to Chat.

The setting for sending messages with Enter or Shift + Enter is separate. See [Conversation preferences](/preferences).
