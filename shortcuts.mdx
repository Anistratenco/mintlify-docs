Use keyboard shortcuts to open search, return to the message box, select a transcript, or open Settings and Files.

Open your profile menu, then choose **Settings → Shortcuts**. The keys shown there are the source of truth for your device and any changes you have made.

## Five useful moves

<div className="mint-grid mint-grid-cols-1 md:mint-grid-cols-2">
  <div className="help-panel">
    <Icon icon="magnifying-glass" size={24} />
    <h3>Find a conversation</h3>
    <p><kbd>⌘ K</kbd> on Mac or <kbd>Ctrl K</kbd> on Windows and Linux opens or closes chat search.</p>
  </div>
  <div className="help-panel">
    <Icon icon="cursor-text" size={24} />
    <h3>Return to the message box</h3>
    <p><kbd>/</kbd> focuses the composer when you are not already typing in an editable field.</p>
  </div>
  <div className="help-panel">
    <Icon icon="text-size" size={24} />
    <h3>Select what you can see</h3>
    <p><kbd>⌘ A</kbd> or <kbd>Ctrl A</kbd> selects the visible transcript when Chat is active and search is closed.</p>
  </div>
  <div className="help-panel">
    <Icon icon="sliders" size={24} />
    <h3>Open Settings</h3>
    <p><kbd>⌘ ,</kbd> or <kbd>Ctrl ,</kbd> takes you straight to Settings and closes chat search.</p>
  </div>
  <div className="help-panel">
    <Icon icon="folder-open" size={24} />
    <h3>Open Files</h3>
    <p><kbd>⌘ ⌥ F</kbd> or <kbd>Ctrl Alt F</kbd> opens the Files workspace and closes chat search.</p>
  </div>
</div>

<Note>
  Selecting a transcript does not copy it. Copy the selection afterward. It is not a full export: messages outside the rendered transcript may not be included.
</Note>

## Make a shortcut yours

<Steps>
  <Step title="Choose the current combination">
    Select the keys beside an action. If that action has no assigned keys, choose **Configure**.
  </Step>
  <Step title="Press the new combination">
    Use the keys together. The app checks for another Anistratenco command using the same combination and for common browser or operating-system shortcuts.
  </Step>
  <Step title="Save the shortcut">
    Choose **Confirm** to save. Choose **Cancel** to keep the previous setting.
  </Step>
</Steps>

<Warning>
  Keep **Focus composer** on <kbd>/</kbd>. That action currently listens for the unmodified key; combinations using Command, Ctrl, or Alt are not handled by it.
</Warning>

## Turn one off

Use the switch beside an action when a shortcut gets in your way. The feature remains available through the interface; only its keyboard combination stops responding.

The reset icon beside a changed action restores its default keys and turns it back on. **Reset shortcuts** does the same for every shortcut. It does not change conversations, files, appearance, or answer preferences.

## When nothing happens

<div className="help-panel">
  <Icon icon="circle-info" size={24} />
  <h3>Check the context first</h3>
  <p>Make sure the shortcut is enabled and use the combination displayed in Settings. For <kbd>/</kbd>, click outside any text field. For transcript selection, close search and return to Chat.</p>
</div>

Some combinations belong to the browser or operating system. If Anistratenco marks one as reserved or already assigned, choose another. The app will not save a known conflict.

Message sending is separate from this list. Choose whether <kbd>Enter</kbd> sends or adds a line from <a className="link" href="/preferences">Preferences</a>.

<section className="help-faq" aria-labelledby="page-questions">
<h2 id="page-questions">Questions. Answers?</h2>
  <Accordion title="Why does Command or Ctrl change by device?"><div>Anistratenco follows the platform selected in your shortcut settings. Automatic uses the device reported by your browser; you can also choose a platform explicitly.</div></Accordion>
  <Accordion title="Why did Command or Ctrl plus A select only the message field?"><div>When the cursor is inside an editable field, select-all stays with that field. Click outside it before selecting the visible transcript.</div></Accordion>
  <Accordion title="Can I restore one shortcut without resetting everything?"><div>Yes. Use the reset icon beside that action. Use **Reset shortcuts** only when you want every combination and enabled state returned to its default.</div></Accordion>
  <Accordion title="Why was my new combination rejected?"><div>It is already assigned to another Anistratenco action or reserved by the browser or operating system. Choose a different combination.</div></Accordion>
  <Accordion title="Does turning a shortcut off remove the feature?"><div>No. It only disables that keyboard combination. The action remains available through the interface.</div></Accordion>
</section>
