Open **Settings → Billing**. Use **Overview** for your plan, **Usage** for activity, **History** for transactions, and **Plans** to compare your options.

## See what you have left

**Overview** shows your current plan and included usage. On Free, the main allowance is shown as messages per day. On a paid plan, it is shown as a monthly usage allowance. The progress bar tells you the percentage **remaining**, with a reset time underneath.

The monthly usage allowance is not the same as a cash balance or an invoice. Check the amount and reset time shown for your account rather than assuming every plan has the same limit.

Choose **Choose plan** or **Change plan** to open Plans. Comparing plans does not buy one. Review the price, billing period, and confirmation before completing a purchase or change.

## Understand the Usage screen

Your main allowance appears here too. When available, two separate counters show:

- **App tool calls:** recorded uses of connected-app tools, with a limit and reset time when one applies.
- **Account files:** the number of stored account files and storage used against the account limit. This is separate from your browser’s local storage.

### Read the activity calendar

**Token activity** displays the latest 90 days. Darker squares represent more recorded activity. Hover over a day—or focus an active square with the keyboard—to see its breakdown.

Tokens are small pieces of text processed by the model. They are not the same as messages. A single conversation turn can involve several model calls or tools.

| Label | What it describes |
| --- | --- |
| Input | Text processed as input |
| Output | Text generated as output |
| Cached | Input recorded as reused from a cache |
| Reasoning | Reasoning-token usage reported by the model |
| Agent turns | Recorded assistant turns |
| Model calls | Individual calls to a model |
| Tool calls | Recorded tool uses |
| Average / turn | Average token usage per recorded turn |

These figures explain activity; they are not an invoice or a direct count of remaining messages. A day with no recorded usage is not proof that no activity occurred if data has not loaded or been recorded yet.

## Find a transaction

Open **History**. Use **Search transactions** and the status filter to narrow the loaded records. Available statuses include Paid, Pending, Released, Refunded, Failed, and Canceled.

Open an item’s details to inspect that transaction. If **Load more orders** is available, use it to retrieve older records. A filtered empty list does not mean there are no earlier orders.

For invoices and payment-method management, use **Manage billing**. Those controls are handled in the secure billing portal, not by typing card details into chat. If no billing customer has been created for your account, the portal may not be available yet.

## Stop automatic renewal

On a paid plan, open **Overview → Cancel** and review the cancellation dialog before confirming. Cancellation is scheduled for the end of the current billing period; access remains until that period ends.

Canceling renewal does not delete your account, erase conversations, or automatically refund the current period. Check the confirmation and the updated renewal state. If the request fails, do not assume renewal has stopped.

## Resume renewal

If cancellation is scheduled, **Resume** appears instead. Choosing it sends the request to turn automatic renewal back on. Check the success message and updated plan state.

## Something does not look right?

If Billing reports a loading problem, retry before treating missing information as zero usage or a canceled plan. For an unexpected charge or a plan that has not updated, [contact us](https://anistratenco.com/contact). Include what you expected, the date, and the visible error. Do not send a full card number, password, or recovery code.
