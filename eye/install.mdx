## Install

Open [Eye for Mac](https://geteye.app/download/) and check for a verified installer. If both versions are available, choose Apple silicon for a Mac that lists an Apple **Chip** in **Apple menu → About This Mac**. Choose Intel if that screen lists an Intel **Processor**. The download lists the minimum macOS version for each build. If there’s no installer link, public downloads are closed.

In **Downloads**, double-click the `.dmg`. Drag **Eye** into **Applications**, then launch it from **Applications**. If you have questions about a macOS warning, compare it with the instructions on the download page or [contact support](https://geteye.app/contact/).

## Confirm tracking

Open Eye from the menu bar. Give Eye camera access when you’re ready, then open **Live** with your face comfortably in view. Wait for a usable reading and blink naturally. Check for a corresponding change in Live. Your daily blink rate needs some usable tracking time before it appears in Today.

If your build offers **Settings → General → Account**, see [Account and updates](/account-and-updates) for sign-in and access. To keep the camera off for now, use **Pause now** in General or leave the permission disabled. [Set up the camera](/camera) covers both paths.
