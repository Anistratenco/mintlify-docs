---
title: Display profiles
description: Adjust soft screen tint and dimming by app, place, time or available light.
icon: monitor
---

In **Settings → Display → Screen appearance**, start with **Default**. Set **Screen tint**, **Tint strength** and **Software dimming**. Software dimming changes the displayed image while your hardware brightness stays where you set it. Use **Reset display** to clear your changes and **macOS Color Filters…** to open the corresponding system controls.

Use **Add app…** to create an override for a foreground app. The foreground app profile takes precedence over your place and bedtime profiles. You can set an app profile to keep a color-sensitive workspace neutral while applying a tint elsewhere.

Under **Saved place**, **Use current location…** saves a place on your Mac after you grant access. Eye can use that display profile within 500 metres. Under **Bedtime**, set bedtime, wake time and **Transition time**, then configure the Bedtime profile. In **Adaptive dimming**, **Dim in low light** uses eligible camera tracking readings to darken the displayed image slightly. If the display looks different from what you configured, first check which app is in front and which profiles are eligible.
